각 항목은 다음 필드를 모두 갖는다:

{
  "name": "모델/제품 이름",
  "announced_date": "YYYY-MM-DD 또는 원문에 없으면 null",
  "confirmed_date": "오늘 날짜(YYYY-MM-DD)",
  "diff": "이전과 달라진 점 — 원문 근거만 요약, 없는 사실을 더하지 않는다",
  "impact": "하네스(프롬프트·추론 설정·컨텍스트 관리·도구 사용)에 대한 적용 제안. 원문에 하네스 변경 설명이 없으면 '공식 문서에 하네스 변경 설명 없음'이라고 쓴다",
  "impact_type": "asserted(원문이 직접 말함) | inferred(우리 판단·제안) | none(하네스 관련 언급 없음)",
  "source_url": "이 사실이 나온 공식 출처 URL — 반드시 위에서 준 출처 URL을 쓴다",
  "related": ["관련 지식 후보 목록에서 고른 실제 항목만. 없으면 빈 배열"]
}

규칙: 원문에 없는 사실을 만들지 않는다. 오래전부터 있던 설명을 새 출시처럼 과장하지 않는다.
같은 변경을 여러 항목으로 쪼개지 않는다. 무관한 절(가격 전수표·마케팅 문구 등)은 무시한다.
바뀐 내용이 실제로 없으면(예: 문구만 재배치) 빈 배열 []만 출력한다.
