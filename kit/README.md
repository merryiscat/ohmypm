# kit/ — 환경 세팅 재료

ohmyPM이 관리 프로젝트의 **처음 환경 세팅**(CLAUDE.md·AGENTS.md 손보기, 스킬 제시, 하네스 구조)을 할 때
넣어 줄 재료를 모아 두는 곳이다. 환경 세팅 기능은 아직 없다(2026-10-11 계획, `docs/design.md` 경계 표).

원칙: **검증을 거친 재료만 넣는다.** 검증 안 된 하네스가 프로젝트를 더 고장 낸 적이 있다(kickoff_pack).
재료마다 상태를 적고, "시험 전"인 것은 환경 세팅에 쓰지 않는다. 검토·판정 기록은 `docs/references.md`.

| 재료 | 넣을 프로젝트 | 상태 |
|---|---|---|
| `skills/web-review/` — 화면 코드 점검표(Vercel 웹 인터페이스 규칙을 한 판으로 고정해 우리말로) | 화면이 있는 프로젝트 | 시험 전 — 화면 프로젝트 하나에 돌려 쓸모를 확인해야 함 |
| `templates/DESIGN.md` — 그 프로젝트 자신의 색·글꼴·간격 + 원칙 + 하지 말 것을 한 장으로. CLAUDE.md에 "화면을 고치기 전에 DESIGN.md를 읽는다" 한 줄과 함께 | 화면이 있는 프로젝트 | 시험 전 — 한 프로젝트에 만들어 넣고, 그 뒤 화면 작업이 덜 들쭉날쭉한지 확인해야 함 |
