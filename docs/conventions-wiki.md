# 위키 규약 (상세)

> CLAUDE.md 블록은 매 턴 규칙만, 여기는 필요할 때 찾아 읽는 상세다.

## 무엇을 적나

- 위키는 git이 못 담는 것만: 결정과 근거, 버그의 증상→원인→**항체(재발 방지 장치)**,
  채택 안 된 대안, 대화에서 오간 아이디어. 코드 수정 이력은 git이 소유한다
- 원본에 있는 주장(asserted)과 종합한 추론(inferred)을 구분해 적는다
- 대화에서 나온 결정은 페이지에 `derived_from: 대화 YYYY-MM-DD`로 출처를 남긴다

## 원본 자료 (raw/)

- 외부 자료·회의록 파일은 `docs/raw/`에 저장(불변) 후 소화한다
- **출처·라이선스 불명 외부 자료는 raw에 넣지 않는다** — 저장소가 공개되는 순간 재배포가 된다

## 실수는 항체까지

실수·비용이 확인되면 버그 페이지(`bug-*`) 또는 실수 연대기에 증상→원인→**항체**를 적는다.
처치 설명으로 끝내지 않는다 — 가드·규칙·린트 같은 **장치**를 만들었는지까지.
같은 실수가 재발하면 항체가 지침이었는지 의심한다: **반복 실패는 지침이 아니라 스크립트·린트로 승격**한다.

## 판정·반영 게이트 (항체)

레퍼런스 keep/drop, 스코프 결정 등 **판정을 문서에 반영하거나 커밋하기 직전**엔 게이트를 통과한다.
근거: [mistakes 2026-08-23 confused-deputy](mistakes.md) — 판정 능력을 확정 권한으로 착각한 실수의 항체.

1. **반영·커밋 전 사용자 확정 필수 — 명백성은 면제 사유가 아니다.** 내 판단은 항상 "권고"까지고,
   keep/drop 확정 클릭은 사용자 몫. "안 갈리니 물을 필요 없다"는 스스로 게이트를 없애는 것(=실수 원인).
2. **확정은 한 건당 한 번으로 절제한다.** 게이트 남발은 automation bias로 검문을 의례화한다 —
   되돌리기 어려운 지점(반영·커밋)에만 건다. 리포 열기·소견 제시는 게이트 없이 진행.
3. **검수 중 `git commit`은 사용자 지시로만.** 되돌리기 경계라 자동 실행 금지(반복 시 permission=ask로 승격).
4. 원리: 판정(action)과 "확정해도 된다"(authority)를 모델이 **동시에 공급하지 않는다**. 확정 정책은 내 재량 밖.

## 위키는 살아있는 것만 남긴다 (다이어트)

위키는 쓰기만 하면 단조 증가한다. 정상 상태는 작다:

- **살아있는 것**: status.md·pending.md — 각 한 화면 이내
- **항체**: 버그 페이지 — 같은 실수가 다가올 때만 읽힘
- **나머지는 흡수 후 삭제 대상** — 반영이 끝난 결정·검토 페이지는 흡수처(규칙·스킬·코드)를
  확인한 뒤 삭제하고 log/provenance 한 줄만 남긴다 (경위는 git 이력이 보존)
- 실험·조사 계열은 종료 시 결과 1장으로 접는다

## 상시 지시 예산

CLAUDE.md의 위키 블록은 **10줄 이하**를 유지한다. 모든 상시 지시는 매 턴 주의력을 지불한다 —
블록에 줄을 더하고 싶으면 먼저 뺄 줄을 찾고, 상세는 이 문서로 보낸다.
