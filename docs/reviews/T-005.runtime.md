# T-005 1.0 실행 구조 확인

검증일: 2026-09-21. 이번 작업은 사용자 예외 승인으로 한 세션에서 구현·검증했다.

- 자동 동작 테스트 31개 통과. 실제 임시 Git 저장소로 승인·기준 변경·병렬 제한·실패 수정·오래된 판정·복구·회수를 검사했다.
- Ruff, 두 스킬 형식, 셸 및 배포 스크립트 문법 검사 통과.
- 설치 재실행의 변경 목록이 비어 있고 플러그인 원본과 프로젝트 실행 도구가 일치한다.
- 실제 Orca에서 작업 환경을 만들고 공용 의존성 링크 없이 작업 포트·데이터를 준비했다.
- `T-005-SMOKE`에서 exec→submit→check→verdict→merge→cleanup을 실행하고 done/cleaned를 확인했다.
- 첫 검증 기록을 생성한 수동 PowerShell 파이프의 ASCII 인코딩 때문에 한글이 손실되었다.
  UTF-8 전달을 명시한 `T-005-LIVE`로 한글 원문·승인 보존을 다시 확인하고, 검증 기준에 한글 본문 검사를 추가했다.

최종 상태는 [T-005 검증 기록](../tasks/T-005-v1-workflow.md)과 로컬 `workflow show --task T-005-LIVE`에서 확인한다.
회수 후에도 실행 로그·보고·판정·작업 데이터는 Git 공통 상태 폴더에 남는다.

실제 유료 worker 모델 실행과 메시지 전송은 이 확인에 포함하지 않았다.
그 호출의 중복·실패 처리는 Orca 대역으로 검사했다. 모델 역할 분담의 품질 우위는 별도 반복 비교 대상이다.
