# T-002 이 PC 프로젝트 시작 환경설정 조사

- 상태: 검토 반영 v2
- 등급: M — 여러 프로젝트의 작업 규약·개발 환경 차이 조사([roles.md](../roles.md)).
- 작성: pl, 2026-09-17

## 목표
에이전트 작업 환경과 개발 실행 환경을 함께 조사한다. 대상·차이·필요 도구 표를 만들어 pl의 후속 스펙 작성에 넘긴다.

## 범위
- 안: 지침·설정·의존성 선언·실행 문서 조사. 지침 비교 기준은 roles·protocol, 단계는 deliverables 문서다. 입력은 **main 체크아웃의 `.env`에서 `PROJECTS_ROOT` 한 키만 단독 조회**하고 **`GET http://127.0.0.1:8123/api/projects`**로 등록 목록을 받는다. main 경로는 pl2 배정문에 명시한다.
- 읽기 금지: `.env` 전체와 나머지 키(대상 프로젝트의 `.env` 포함), `*.key`, `*.pem`, 자격증명 든 MCP 설정, `data/`. MCP 파일의 무자격증명 여부가 불명확하면 열지 않고 접근제한으로 기록한다.
- 밖: 대상 수정, 설치·앱 코드 실행·테스트·서버 기동, DB 직접 조회, GET 외 API 호출, 외부 발신. 후속 스펙 본문인 수정 파일·변경안·적용 순서·확인/원복 절차도 작성하지 않는다.

## 완료 기준 (기준 하나에 확인 방법 하나)
1. [ ] 유효한 관리 루트와 API 등록 목록을 확보했다. main 경로·키·루트 미확인, API 미기동/GET 실패 또는 조사 대상 0건이면 실패다. 빈 표를 성공으로 보고하거나 서버 기동·DB 조회로 우회하지 않는다. — 확인: 키 단독 조회 결과·루트 존재·GET 응답 기록을 대조한다.
2. [ ] 대상표에 루트 발견 목록과 등록 목록의 차이, 중복·중첩 워크트리 정리 결과, 내 프로젝트/외부 클론/보관/미확인 분류가 있다. — 확인: 두 입력 목록과 대상표를 행별 대조한다.
3. [ ] 프로젝트별 지침·역할·절차·템플릿·스킬/MCP/훅의 현재 상태와 기준 대비 차이·근거 파일을 적는다. 없음/미확인/접근제한을 구별하며 변경안은 쓰지 않는다. — 확인: 허용된 근거 자료와 차이표를 대조한다.
4. [ ] **케이스 5개 초과·운영 환경·되돌리기 어려운 변경 중 하나라도 해당하면 작업 구조 필요**로 표시한다. 모두 비해당이면 불필요, 해당 근거 없이 미확인 조건이 남으면 판단 대기다. 외부 클론·보관은 적용 대상 외로 구분한다. — 확인: 세 조건의 증거와 이 스펙의 판정 규칙을 대조한다.
5. [ ] 개발 환경표에 런타임·패키지 관리자·잠금파일·환경변수 이름·기존 실행/종료 명령·포트·연동과 필요한 도구의 이름·용도·출처·버전 근거가 있다. 허용된 문서·선언 파일만 출처로 쓰고 비밀값은 수집하지 않으며 불명 항목은 미확인으로 적는다. — 확인: 표와 허용된 근거 파일을 대조한다.
6. [ ] 확인일·조사 범위와 지침 충돌·git 없는 대상 등 미결 사유를 표에 기록한다. 대상·차이·필요 도구 밖의 후속 설계나 설치 결정을 대신하지 않는다. — 확인: 표의 각 행에 조사 근거·미결 표시가 있는지 읽는다.
7. [ ] 산출물은 **로컬 전용** `docs/setup-rollout.md`이며 gitignore 대상·git 미추적 상태다. 워크트리 전달은 사용자 결정대로 `.worktreeinclude` 복사를 사용한다. 설정 누락은 실패로 보고하고 강제 추가·공개 등재로 우회하지 않는다. — 확인: 제외·추적 상태와 복사 설정을 읽어 확인한다.
8. [ ] 변경은 산출물 한 파일뿐이며, 완료 보고에 기준별 통과/실패와 실제 확인 방법을 적는다. 미실행·입력 부족은 실패로 보고하고 환경설정 적용 완료라고 쓰지 않는다. — 확인: 변경 내역과 완료 보고를 대조한다.

## 손대는 파일
- `docs/setup-rollout.md` — 로컬 조사표만 작성. index·gitignore·.worktreeinclude·대상 프로젝트는 수정하지 않는다.

## 필요 도구
설치 없음. 기존 파일·폴더 조회, git 읽기 기능, PowerShell의 키 단독 조회·HTTP GET을 허용한다. 허용 API는 위 등록 목록 조회뿐이며 금지 파일을 읽는 도구 우회는 허용하지 않는다.
