## 1부 요약

ohmyPM은 사용자의 모든 로컬 프로젝트를 매일 돌보는 **메타 PM 에이전트**다. 킥오프팩을
만들면서 확인한 문제 — 하네스 엔지니어링과 프로젝트 환경 관리가 부실하면 모델 품질이 확
떨어진다 — 를 해결하기 위해, 프로젝트 매니저가 할 일을 에이전트가 매일 대신 수행한다.
형태는 **Claude Code 기반 에이전트**(스킬 + 스케줄, 별도 앱·화면 없음)이고, MVP 범위는
① 환경·하네스 점검(CLAUDE.md·스킬·훅·설정의 부패/노후 감지·업데이트), ② 진행 상황
추적 + 데일리 브리핑(오늘 할 일 제안·우선순위·일정 제시), ③ 문서·위키 건강 관리(llmwiki
lint 연계), ④ 자율 업무 실행(사용자 판단이 필요 없는 업무는 직접 처리)이다. 보고 채널은
**텔레그램 알림**. 산출물은 코드/하네스(스킬·스케줄 구성)다.
