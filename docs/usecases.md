## 선결 과제 (확보 전 해당 케이스 착수 불가)

- **벤치 과제셋 + 평가지표 설계** (케이스 1의 선결) — **프론티어 모델도 어려운 난이도**여야 하네스 차이가 점수에 드러난다(변별력). **별도 프로젝트로 분리 확정(2026-08-25 사용자 결정)** — ohmyPM은 그 결과물(과제셋)을 받아 쓰는 쪽. 별도 프로젝트 완료 전엔 케이스 1 착수 불가(나머지 17개는 무관하게 진행).

## 공통 전제 (여러 케이스가 밟는 토대)

- **관리 대상 프로젝트 목록·스캔** — `C:\Users\minhy\project` 하위 실측 40개 폴더 중 docs 위키 있는 건 ~18개, 나머지 ~22개는 위키 없음. 무엇을 관리 대상으로 등록하나(전부/지정)는 plan 미확정 → 대시보드가 이 결정을 요구
- **llmwiki 표준 규격** — 파싱·표준화의 기준. 프로젝트마다 형식이 다름(실측: odin status는 `## 날짜별` 섹션, ohmyPM은 `진행중/미해결/최근완료` — 같은 llmwiki인데도 상이). kickoff_pack llmwiki가 규격 원천
- **자율 행동 안전장치** — git 커밋·diff·롤백으로 되돌릴 수 있게. **급소: "무엇이 안전한 자율 업무인가"를 ohmyPM이 자가판단하면 confused-deputy**([[mistakes]]·plan 자율경계). 사전 분리 최종안의 실행 계층
