# T-NNN 작업 스펙

- 상태: 설계 중 / 사용자 논의 / 구현 승인 / 구현 중 / 검증 중 / 완료
- 버전: 1
- 요청 원문: 사용자 말을 그대로 기록

## 목표와 결정
용도·범위·제외 대상·사용자와 결정한 근거. 논의 횟수 제한 없이 합의한다 [P-03].

## 완료 기준
관찰 가능한 기준. 기준마다 확인할 입력·동작·통과 조건·검증 방법 하나 [P-03].
명령으로 검사할 기준과 pl이 실제 동작으로 확인할 기준을 manifest에 대응시킨다 [P-08].

## 작업과 하네스
work별 소유 경로·의존성·자원·기준·도구·설정. 병렬 가능하면 독립성 근거를 적는다 [P-06].
기존 도구 우선, 필요한 확장은 사용자와 설계에서 합의한다. manifest와 함께 버전을 고정한다 [P-05].

## 사용자 결정
질문·답변과 해당 버전의 실제 구현 요청. 스펙 변경은 재합의한다 [P-07].

## 상시 규칙으로 남는 결정
이 작업의 결정 중 다음 작업에도 적용될 것만. 없으면 "없음". 반영 위치는 프로젝트 지침(CLAUDE.md·docs)
또는 ohmyPM 자체 작업이면 PROTOCOL.md의 P-ID. 이유가 없는 규칙은 승격하지 않고 여기서 묻는다 [P-20].
